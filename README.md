# 🎮 Isaiah Smile B. Halik — Personal Portfolio

A retro/RPG-themed personal portfolio website designed to showcase my web development journey, academic achievements, and coding projects. Built with a "Player Profile" aesthetic, this site treats my experiences and projects as quests, items, and trainer stats.

🔗 **[View Live Site Here](https://ihalik250000000758-blip.github.io/)**

---

## 🗺️ Site Navigation & Features

The portfolio is divided into several themed sections:

*   **🕹️ Player Profile (Hero):** Introduction and quick links to contact and projects.
*   **📜 Quest Board (Activities):** A log of completed side quests, including a Fashion Blog layout, Wine Festival Schedule, and Davies Burger landing page.
*   **📊 Trainer Stats (Skills):** A 5-star rating system showcasing my proficiency in programming (Java, HTML, CSS) and design (Canva, Adobe Illustrator, Photoshop).
*   **🎒 Item Box (Projects):** Featured builds and research, including an *Automatic Dog Feeder Using Arduino* and a *Student Class Records System*.
*   **🏆 Trophy Hall (Academic Achievements):** A timeline of my academic excellence, featuring Grade 11 and Grade 12 High Honor certificates.
*   **📖 Journey Log (Experiences):** My background as an Assistant Programmer and STEM Researcher.
*   **💾 Save Point (Contact):** Quick access to my GitHub profile.

---

## 🛠️ Tech Stack

This project was built from scratch using core web technologies:

*   **HTML5:** Semantic structure and organization.
*   **CSS3:** Custom styling, flexbox/grid layouts, responsive design, and RPG-themed UI components.
*   **Vanilla JavaScript:** 
    *   Mobile hamburger menu toggle.
    *   Smooth scrolling for anchor links.
    *   Dynamic star-rating generator for the Skills section.
    *   Scroll-spy active link highlighting in the navigation bar.
*   **Typography:** Google Fonts (`Press Start 2P` and `VT323`).
*   **Icons:** FontAwesome 6.
